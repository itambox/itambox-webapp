# Dashboards

Dashboards provide configurable summaries of ITAMbox data using widgets. They are useful for operational views such as hardware state, upcoming renewals, recent changes, or customer-specific metrics.

Dashboard data follows the active workspace and the user's access. A Tenant Group or **All Tenants** workspace can therefore produce aggregate views where the widget supports them; a dashboard does not bypass authorization.

## Managing Dashboards

You can create multiple dashboards for different purposes and choose a default. For example, an MSP operator might keep one cross-customer operations dashboard and separate customer-focused dashboards.

## Editing A Layout

Layouts are normally locked to prevent accidental changes. Unlock the dashboard before adding, moving, resizing, or removing widgets. Save the layout when the arrangement is complete, then lock it again for normal use.

Widget configuration is independent from physical placement. Open a widget's settings to change its title, limits, date range, or supported filters.

## Workspace Changes

Switching workspace changes the data context. Do not interpret a lower count after switching customers as missing data until you confirm the selected workspace. See [Workspaces](features/workspaces.md).
