# SaaS Providers

A **SaaS Provider** represents a cloud platform hosting provider, software vendor, or web application developer offering subscription services (e.g. `Figma`, `AWS`, `Salesforce`, `Atlassian`).

## Fields

### Account ID

Customer account number with this provider.

### Admin Notes

Internal administrative notes.

### Contacts

Assigned contacts from the unified organization contact system.

### Active

Toggle to show/hide this provider in selections.

**Required:** Yes.

### Name

Unique name of the SaaS provider (e.g., Adobe Inc.).

**Required:** Yes.

### Admin Portal URL

Administration or configuration management console portal link.

### Slug

URL-friendly identifier (auto-generated if blank).

**Required:** Yes.

### Tenant

Optional tenant scoping this provider. Null represents system-wide/global.

### Tenant Group

Optional tenant group scoping this provider.
