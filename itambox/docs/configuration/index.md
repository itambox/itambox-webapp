# Configuration

Configuration controls deployment-level behavior: environment variables, authentication providers, workers, security settings, retention, feature activation, and other choices made by the operator rather than an ordinary application user.

The canonical environment-variable inventory remains [Installing ITAMbox](../operations/installation.md) together with `.env.example` in the repository. This section explains how groups of settings affect product behavior.

- [Authentication](authentication.md)
- [Background Jobs](background-jobs.md)
- [Feature Activation](feature-activation.md)
- [Deployment Security](../security/deployment-security.md)
- [Data Retention](../operations/data-retention.md)

Do not copy secrets or production values into documentation, tickets, or screenshots. Document the setting name and behavior instead.
